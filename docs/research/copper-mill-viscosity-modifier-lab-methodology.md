# Методика лабораторных испытаний модификатора вязкости МВ-Cu

**Назначение:**
1. Выбрать состав реагента из кандидатов.
2. Подобрать дозировку.
3. Подтвердить, что реагент не ухудшает флотацию и сгущение медного концентрата.
4. Оценить экономический эффект.

**Связанные документы:**
- [Обзор патентов и рецептура МВ-Cu](copper-mill-viscosity-modifier.md)
- Калькулятор: [`mv-cu-lab-economics.xlsx`](mv-cu-lab-economics.xlsx) — выбор дозы, экономика, чувствительность, скоринг составов.

**Версия:** 1.0, 30.09.2026

---

## 1. Общие принципы

1. **Каждый опыт сравнивается с холостым опытом (без реагента).** Условия одинаковые: та же навеска руды, та же оборотная вода, те же мелющие тела, тот же оператор, тот же день.
2. **Руда, вода и мелющие тела — заводские.**
   - Вода: оборотная вода фабрики, не водопроводная. Ca²⁺, Cu²⁺ и остатки реагентов определяют поведение полимера.
   - Мелющие тела: кованая или литая сталь, как в мельнице. Продукты окисления железа маскируют действие диспергаторов, а на нержавеющих телах эффект получается завышенным.
3. **Реагент дозируется по активному веществу (г/т сухой руды).** Рабочий раствор — 1 % по активу на оборотной воде. Готовится ежедневно.
4. **Реагент вводится туда же, куда на фабрике, — в мельницу.** Добавка в уже измельчённую пульпу допустима только на экспресс-скрининге (этап 1а).
5. **Повторности:**
   - реология и измельчение — не меньше 2 (при разнице между повторами больше 10 % — третий опыт);
   - флотация — не меньше 3.
   - Холостой опыт ставится **каждый рабочий день** для контрольной карты.
6. **Порядок опытов рандомизируется внутри дня**, чтобы исключить дрейф из-за окисления руды и температуры.
7. **Решение по составу принимается поэтапно («воронка»).** Дорогие флотационные опыты и опыты на сгущение ставятся только для 2–3 лучших кандидатов после дешёвого реологического скрининга.

## 2. Отбор и подготовка проб

### 2.1. Руда
- **Технологическая проба:** 300–400 кг питания мельниц (с конвейера, по ГОСТ/стандарту фабрики, за 5–7 суток), представительная для текущего плана горных работ. Бюджет руды — в разделе 12.
- **Дробление** до −3,35 мм, усреднение (кольцо-конус, затем желобчатый делитель). Навески:
  - 2,0 кг — для измельчения;
  - 1,0 кг — для флотации;
  - 0,5 кг — для реологии.
- **Хранение:** навески в герметичных пакетах, по возможности под азотом или в морозильнике (−18 °C). Весь цикл испытаний — в пределах 6–8 недель: окисление сульфидов меняет флотируемость.
- **Характеристика исходной пробы:**
  - химический анализ: Cu общая и окисленная, Fe, S, Mo, Au, Ag, CaO, MgO, Al₂O₃, SiO₂;
  - гранулометрический состав;
  - **минералогия пустой породы** (XRD или QEMSCAN/MLA): доля глин (каолинит, монтмориллонит, серицит, хлорит), карбонатов, оксидов железа. По ней выбирается вариант рецептуры (S, C или O — см. раздел 5 отчёта).

### 2.2. Оборотная вода
- 200–300 л из того же водооборота, что и питание мельниц. Хранить при 4 °C, использовать не дольше 2 недель.
- Анализ на входе и затем раз в неделю: pH, Ca²⁺, Mg²⁺, Cu²⁺, Fe, SO₄²⁻, Cl⁻, ТОС, мутность, остаточный ксантогенат.

### 2.3. Заводские реагенты
- Известь, собиратель, вспениватель, депрессоры — заводские партии.
- Флокулянты сгустителей концентрата и хвостов — заводские партии; маточный раствор готовить по регламенту фабрики.
- **Контрольная проба заводских продуктов** (для этапа 1б): пульпа слива шаровой мельницы (питание гидроциклонов), 20 л.

## 3. Кандидаты и входной контроль (этап 0)

### 3.1. Матрица кандидатов

| Код | Кандидат | Зачем в матрице |
|---|---|---|
| R0 | Холостой опыт | База сравнения |
| R1 | Na-полиакрилат, Mw около 5 тыс. | Классика Dow (US4162044); дешёвый эталон |
| R2 | АК/AMPS 90:10 | Влияние доли сульфомономера |
| R3 | АК/AMPS 75:25 | **Компонент A** рецептуры МВ-Cu |
| R4 | АК/AMPS 60:40 | Влияние доли сульфомономера |
| R5 | Терполимер АК/AMPS/трет-бутилакриламид, Mw около 4,5 тыс. | **Компонент B** (GE Betz) |
| R6 | МВ-Cu-S (A:B = 30:8 по активу) | Базовая рецептура |
| R7 | АК/AHPSE | Вариант для оксидной породы (GE Betz) |
| R8 | Коммерческий эталон (Solenis Zalta, продукт Ecolab/Nalco или аналог) | Ориентир по рынку, если образец доступен |
| R9 | Глюконат натрия | Опция МВ-Cu-G (Klimpel, US5799882) |

**Молекулярная масса:** для лучшего из R2–R4 дополнительно проверяются образцы с Mw около 2–3 тыс. и около 10–15 тыс. Смешивать образцы разной Mw нельзя: для этого нужны отдельные образцы.

**Оптимизация смеси A:B (этап 1в)** — симплекс-решётка из трёх точек с шагом 25 % по активу: 100:0, 75:25 (≈ МВ-Cu-S), 50:50.

### 3.2. Входной контроль каждого образца
Показатели: сухой остаток и активное вещество (%), pH, плотность, вязкость по Брукфилду, Mw и PDI по ГПХ (данные поставщика или внешняя лаборатория). Исходные данные образцов и паспорта безопасности хранятся в журнале.

### 3.3. Тест на стабильность в жёсткой воде (барьер, этап 0)
1. Приготовить раствор реагента 0,1 % и 0,01 % по активу в оборотной воде.
2. Довести pH известковым молоком до рабочего pH мельницы или флотации (обычно 10,5–11,5).
3. Выдержать 24 ч при 20 °C.
4. **Критерий:** нет осадка и опалесценции, мутность выросла не больше чем на 5 NTU относительно воды с известью без реагента.

Дополнительно для товарной формы:
- 3 цикла заморозки и оттаивания (−15 °C / +20 °C) — нет расслоения и осадка;
- совместимость с известковым молоком 10 % при прямом смешении.

Кандидат, не прошедший барьер, дальше не испытывается. Ожидается, что чистый полиакрилат R1 может отсеяться именно здесь.

## 4. Этап 1. Реологический скрининг

### 4.1. Оборудование
- Ротационный реометр или вискозиметр с **лопастным ротором (vane)** — для предела текучести. Коаксиальные цилиндры или спиральный ротор — для кривой течения.
  - Диаметр лопасти — не меньше 10 размеров максимальной частицы.
  - Зазор до стенки стакана — не меньше диаметра лопасти.
- Термостатирование: температура пульпы в мельнице фабрики ±1 °C.
- Верхнеприводная мешалка, весы 0,01 г, влагомер или сушильный шкаф для контроля содержания твёрдого (Cw).

### 4.2. Подготовка пульпы
- **Этап 1а (экспресс):** руду измельчить в лабораторной мельнице без реагента, на оборотной воде с известью до pH фабрики, до **P80 слива мельницы**. Отфильтровать. Кек и фильтрат использовать для пульп с заданной плотностью. Реагент добавлять в готовую пульпу и перемешивать 5 мин.
- **Этап 1б (контроль):** та же процедура на заводской пульпе слива мельницы (раздел 2.3). Показывает, воспроизводится ли эффект на реальном продукте.
- **Этап 1в (подтверждение):** реагент вводится **в мельницу**, реология измеряется на продукте помола. Выполняется для 3–4 лучших кандидатов.

### 4.3. Матрица опытов
- **Содержание твёрдого Cw:** рабочее значение фабрики, затем +3 п.п. и +6 п.п. Если рабочее неизвестно — 65, 70, 75 и 78 % масс.
- **Дозы:** 0, 50 и 100 г/т по активу (скрининг); 0, 15, 30, 50, 75, 100, 150 г/т (этап 5).

### 4.4. Процедура измерения
1. Предварительный сдвиг: 60 с при 100 с⁻¹.
2. Покой 10 с.
3. **Предел текучести τy** — лопастным ротором при постоянной малой скорости (0,2–0,5 об/мин) по пиковому моменту M:

   τy = 2M / [π·D³·(H/D + 1/3)],

   где D и H — диаметр и высота лопасти.
4. **Кривая течения** — ступенчато вниз, 300 → 10 с⁻¹, 8–10 точек по 5 с. Короткие ступени нужны, чтобы крупные частицы не успели осесть.
5. Аппроксимация: модель Бингама (τB, ηpl) и Гершеля–Балкли (τ0, K, n).
6. Сразу после измерения — контроль Cw по пробе из стакана (сушка при 105 °C).

### 4.5. Результаты и критерии
- **Снижение предела текучести** при рабочей Cw + 3 п.п. и дозе 50 г/т:

  Δτy = 1 − τy(R) / τy(R0).

- **ΔCw — «выигрыш по плотности»** (главный показатель этапа).
  1. По кривым τy(Cw) найти Cw, при которой пульпа с реагентом имеет **тот же τy, что холостая пульпа при рабочей Cw**.
  2. ΔCw = Cw(R) − Cw(R0), п.п.
  3. Это прямая оценка того, насколько можно уплотнить пульпу в мельнице без потери текучести.
- **Критерий прохода на этап 2:** Δτy ≥ 25 % и ΔCw ≥ 2 п.п. при 50 г/т.
- **Экономический фильтр:** стоимость продукта на 1 п.п. ΔCw ($/т руды на п.п.). Считается на листе «Скоринг составов».
- **Отбор:** на этап 2 проходят 3 лучших состава.

## 5. Этап 2. Кинетика мокрого измельчения

### 5.1. Оборудование и режим
- **Мельница:** лабораторная шаровая периодического действия, например ∅250 × 300 мм, футеровка с лифтерами.
  - Скорость — 70–75 % критической. Nкр = 42,3/√D, об/мин, D в метрах; для D = 0,25 м это 85 об/мин, рабочая скорость около 60 об/мин.
- **Шаровая загрузка:** кованая сталь, как на фабрике, 30–35 % объёма барабана. Распределение по крупности — масштабированное заводское, например 40/30/20 мм = 30/40/30 %.
- **Руда:** около 2 кг −3,35 мм. Навеска подбирается так, чтобы пульпа заполняла пустоты шаровой загрузки (U ≈ 1).
- **Жидкость:** оборотная вода. Известь — в той же дозе на 1 т, что на фабрике. Реагент — вместе с водой в начале помола.
- **Энергия:** ваттметр на приводе. Чистая мощность = мощность под нагрузкой − мощность холостого хода.

### 5.2. Матрица опытов
- **Плотности:** рабочая Cw и Cw + 3 п.п. Для кандидата с ΔCw ≥ 4 п.п. — ещё Cw + 6 п.п.
- **Реагент:** R0 и 3 лучших кандидата при 50 г/т.
- **Время помола:** 4 точки, например 4, 8, 12 и 16 мин. **Каждая точка — отдельная загрузка.** Отбор проб с остановкой мельницы искажает результат.
- **После каждого помола:**
  - мокрый рассев на ситах 1180 … 38 мкм (+ лазерная дифракция для фракции −38 мкм);
  - pH, Eh и растворённый кислород в сливе;
  - реология слива (выборочно);
  - **EDTA-экстрагируемое Fe** (показатель продуктов окисления мелющих тел).

### 5.3. Расчёт
1. **Время до целевой P80** (P80 слива гидроциклонов фабрики): t80 — логарифмическая интерполяция зависимости P80(t).
2. **Удельная энергия до целевой P80:** E80 = ∫P dt / m руды, кВт·ч/т.
3. **Константа скорости разрушения** верхнего класса −1180+850 мкм (первый порядок): ln[m(t)/m(0)] = −k·t.
4. **Лабораторный прирост производительности** при одинаковой Cw:

   δQ(лаб) = t80(R0) / t80(R) − 1.

   Этот показатель вносится на лист «Доза-отклик» калькулятора.
5. **Сценарий уплотнения:** t80 для R при Cw + 3 п.п. против R0 при рабочей Cw.
   - При более плотной пульпе мельница пропускает больше руды за то же время пребывания.
   - Ожидаемо: без реагента при Cw + 3 п.п. t80 растёт (зона предела текучести по Klimpel), с реагентом — нет.

### 5.4. Критерии
- δQ(лаб) ≥ 4 % при Cw + 3 п.п. и 50 г/т.
- Продукт не переизмельчён: доля −10 мкм при той же P80 не выше, чем у холостого опыта (+1 п.п. допуск). Переизмельчение ухудшает флотацию и сгущение.
- Отбор: на этапы 3 и 4 проходят 2 лучших состава.

## 6. Этап 3. Флотация (барьер «не меняет флотацию»)

### 6.1. Подготовка
1. Помол 1 кг руды в стержневой или шаровой мельнице при рабочей Cw, с известью и **реагентом в мельнице**.
2. **Каждая схема доводится до одинаковой P80 (±5 %)** подбором времени по калибровочной кривой этапа 2.
   - Так отделяется химическое влияние реагента от влияния крупности.
   - Эффект более тонкого помола оценивается отдельно, по данным этапа 2.
3. Перенос в флотомашину (механическая, 2,5–3 л). Разбавление оборотной водой до Cw флотации фабрики (30–35 %).

### 6.2. Схема
- **Реагентный режим** — строго заводской: pH, собиратель, вспениватель, время кондиционирования.
- **Основная флотация, кинетический режим:** концентраты за 0–0,5, 0,5–1, 1–2, 2–4, 4–8 (и 8–12) мин. Съём пены — постоянной частотой (например, каждые 10 с).
- Если на фабрике есть перечистка — **открытая перечистка** объединённого концентрата основной флотации (1–2 перечистки).
- **Регистрация:** pH, Eh, температура, масса и объём воды каждого продукта (извлечение воды — для оценки механического выноса), визуальная характеристика пены (размер пузырей, устойчивость; фото).

### 6.3. Анализы
Все продукты на Cu, Fe, S (плюс Mo, Au, нерастворимый остаток — если важны для фабрики).

### 6.4. Матрица опытов
| Схема | Доза, г/т по активу | Повторности |
|---|---|---|
| R0 холостой | 0 | 4–5 (оценка σ) |
| Кандидат 1 | 1× (50) | 3 |
| Кандидат 1 | **3× (150)** — проверка передозировки | 3 |
| Кандидат 2 | 1× и 3× | по 3 |
| **Стресс-тест Cu²⁺:** R0 и кандидат 1 при 3×, оборотная вода + CuSO₄ до 5 мг/л Cu²⁺ | 0 / 150 | по 2 |

Стресс-тест нужен потому, что Cu²⁺ резко усиливает адсорбцию полиакрилата на халькопирите (Minerals 2026, 16(5), 449).

### 6.5. Обработка
1. **Кривые «извлечение – время».** Аппроксимация моделью Klimpel:

   R(t) = R∞ · [1 − (1 − e^(−k·t)) / (k·t)].

   Сравниваются R∞ и k.
2. **Кривые «содержание – извлечение».** Сравниваются при одинаковом извлечении Cu (например, 85 %):
   - содержание Cu в концентрате;
   - извлечение Fe и S в концентрат (селективность против пирита);
   - извлечение нерастворимого остатка или воды (механический вынос).
3. **Статистика:**
   - σ — стандартное отклонение извлечения Cu по повторам холостого опыта;
   - сравнение — t-критерий Стьюдента (α = 0,05) и **тест эквивалентности TOST** с допуском δ.
   - Число повторов на схему: n ≈ 2·(z₁₋α + z₁₋β/₂)²·σ²/δ².
     - При σ = 0,4 % и δ = 1,0 % абс. получается n = 3.
     - При σ = 0,7 % нужно n = 9–10.
     - **Лабораторная флотация не может доказать равенство точнее ±0,5–1 % абс.** Более тонкая проверка — только в промышленных испытаниях.

### 6.6. Критерии барьера (при дозе 1×)
- Извлечение Cu: разница с холостым опытом эквивалентна нулю в пределах **±1,0 % абс.** (TOST, α = 0,05). Среднее не ниже холостого более чем на 0,5 % абс.
- Содержание Cu в концентрате при равном извлечении: в пределах ±0,5 % абс. (для концентрата с 20–28 % Cu).
- Извлечение Fe/S и воды в концентрат — не выше холостого опыта более чем на 10 % отн.
- Пена визуально не меняется.
- **При дозе 3×:** снижение извлечения Cu не больше 2 % абс. Это запас на ошибки дозирования и накопление реагента.
- **Стресс-тест Cu²⁺:** при 3× снижение не больше 3 % абс. Если больше — нужен состав с большей долей AMPS.

## 7. Этап 4. Сгущение и фильтрование (барьер «не меняет сгущение»)

### 7.1. Материал
- **Концентрат** — объединённые концентраты флотационных опытов этапа 3.
- **Хвосты** — отвальные хвосты, для каждой схемы и дозы (R0, 1×, 3×).
- Разбавить оборотной водой до плотности питания соответствующего сгустителя фабрики.

### 7.2. Тесты в цилиндрах (500 или 1000 мл)
1. **Флокулянт:** заводской. Маточный раствор 0,25 %, созревание не меньше 1 ч. Рабочий раствор 0,025 %.
2. **Дозирование:** шприцем, одинаковое для всех схем (например, 3 порции с 3 переворачиваниями цилиндра). Методика фиксируется и не меняется.
3. **Дозы флокулянта:** 3–4 уровня вокруг заводской дозы, например 0,5×, 1× и 1,5× заводской (г/т).
4. **Регистрация:**
   - граница осветления во времени → **начальная скорость осаждения** (м/ч, линейный участок);
   - **мутность слива** (NTU) через 10 и 60 мин;
   - высота и **плотность осадка** через 24 ч (уплотнение);
   - **остаточный полимер в сливе** (раздел 8).
5. **Главная метрика:** **доза флокулянта, дающая целевую скорость осаждения** (как на фабрике). Определяется интерполяцией по кривой «доза флокулянта – скорость».

### 7.3. Фильтрование концентрата
- Лабораторный фильтр-пресс или вакуум-фильтр в режиме заводского фильтра.
- Показатели: производительность (кг/м²·ч), **влажность кека**, прозрачность фильтрата.

### 7.4. Критерии барьера (при дозе 1×)
- Доза флокулянта для целевой скорости осаждения — не выше холостой более чем на 10 % отн.
- Мутность слива — в пределах норматива оборотной воды фабрики и не выше холостой более чем на 20 % отн.
- Плотность осадка — не ниже холостой более чем на 1 п.п.
- Влажность кека концентрата — не выше холостой более чем на 0,3 п.п.
- **Если барьер не пройден:**
  1. повторить тест с анионным флокулянтом, содержащим сульфогруппы (подход Solenis, WO2016036843);
  2. если такой флокулянт снимает влияние, записать это как условие применения.
  3. Изменение расхода флокулянта вносится в калькулятор (лист «Исходные», строка 21).

## 8. Этап 4б. Адсорбция и остаточная концентрация реагента

**Цель** — оценить, сколько реагента остаётся в растворе на флотации и в сгустителях, и проверить расчёт из отчёта (единицы ppm).

1. **Аналитика анионного полимера в фильтратах:**
   - **коллоидное титрование** раствором полиДАДМАХ (индикатор толуидиновый синий или детектор потока) — предел около 1 мг/л;
   - либо **ТОС** с калибровкой по холостому фильтрату;
   - для промышленных испытаний можно заказать у производителя полимер с флуоресцентной меткой.
2. **Изотерма адсорбции:**
   - пульпа 30 % твёрдого (продукт измельчения до P80), оборотная вода, pH рабочий;
   - концентрации полимера 0, 5, 10, 25, 50, 100, 200 мг/л; перемешивание 30 мин;
   - центрифугирование, анализ фугата;
   - Γ = (C₀ − C)·V / m, мг/г; аппроксимация уравнением Ленгмюра.
3. **Расчёт остаточной концентрации:** по изотерме и водному балансу фабрики (м³ воды на 1 т руды в мельнице, на флотации, в сгустителях) — ожидаемая остаточная концентрация при выбранной дозе.
4. **Критерий:** расчётный остаток на флотации не больше 1/10 концентрации, при которой начинается депрессия халькопирита в стресс-тесте этапа 3.

## 9. Этап 5. Подбор дозировки

Выполняется для **одного выбранного состава**.

### 9.1. Опыты
| Метод | Дозы, г/т по активу | Условия |
|---|---|---|
| Реология (этап 1в) | 0, 15, 30, 50, 75, 100, 150 | Рабочая Cw и Cw + 3 п.п. |
| Измельчение (этап 2) | 0, 15, 30, 50, 75, 100, 150 | Cw + 3 п.п.; t80 и E80 |
| Флотация (этап 3) | 0, D_opt, 2·D_opt, 3·D_opt | 3 повторности |
| Сгущение (этап 4) | 0, D_opt, 3·D_opt | Концентрат и хвосты |

### 9.2. Определение доз
1. **Кривая «доза – отклик»** для ΔCw и δQ(лаб). Аппроксимация моделью насыщения:

   Y(D) = Y_max · (1 − e^(−D/D₀)).

2. **D_тех — техническая доза:** доза, дающая 80 % от Y_max, то есть D ≈ 1,6·D₀.
3. **D_опт — экономически оптимальная доза:** максимум чистого эффекта на листе «Доза-отклик».
   - Вносятся: t80, прирост извлечения, отметки прохождения барьеров флотации и сгущения по каждой дозе.
   - Калькулятор учитывает только дозы, прошедшие оба барьера.
4. **D_max — максимальная безопасная доза:** наибольшая доза, прошедшая оба барьера.
5. **Правило выбора:** D_опт ≤ D_max / 3.
   - Трёхкратный запас покрывает ошибки дозирования, колебания производительности и накопление реагента в водообороте.
   - Если условие не выполняется, берётся D = D_max / 3. Калькулятор показывает фактический запас.
   - Пример в калькуляторе: D_опт = 50 г/т, D_max = 100 г/т, запас 2,0×. Значит, нужно либо испытать дозу 150 г/т повторно, либо снизить дозу до 30–35 г/т.
6. **Стартовая доза для промышленных испытаний:** выбранная доза. Диапазон регулирования при испытаниях — ±30 %.

### 9.3. Этап 6. Замкнутый цикл по воде (подтверждение при выбранной дозе)
1. 5–6 последовательных циклов: помол с реагентом → флотация → сгущение хвостов с флокулянтом.
2. **Слив цилиндра** — вода для помола и флотации в следующем цикле (с подпиткой свежей оборотной водой по балансу фабрики).
3. **Контроль в каждом цикле:** извлечение и содержание Cu, остаточный полимер в сливе, Ca²⁺, мутность, скорость осаждения.
4. **Критерий:** нет монотонного тренда ухудшения по циклам. Наклон регрессии статистически незначим, либо изменение не больше 1 % абс. за 6 циклов.

## 10. Выбор состава: итоговая матрица

Лист «Скоринг составов» калькулятора.

1. **Барьеры (1 = пройден, 0 = не пройден):** Ca-стабильность (этап 0), флотация (этап 3), сгущение (этап 4). Состав, не прошедший хотя бы один барьер, выбывает.
2. **Балл для прошедших:**

   Балл = w₁·ΔCw/max + w₂·Δt80/max + w₃·min(стоимость)/стоимость.

   Веса по умолчанию: 0,35 / 0,35 / 0,30. Стоимость — $/т руды при 50 г/т.
3. **Победитель** идёт на этап 5.
4. **Если два состава различаются меньше чем на 5 % балла**, выбирается тот, у которого:
   - больше запас по дозе (D_max / D_опт);
   - меньше чувствительность в стресс-тесте Cu²⁺.

## 11. Экономическая эффективность

Расчёт — в калькуляторе [`mv-cu-lab-economics.xlsx`](mv-cu-lab-economics.xlsx). Входные данные — на листе «Исходные», результаты — на листе «Экономика».

### 11.1. Формулы
Обозначения:
- Q₀ — базовая производительность, т/ч; H — часы работы в год;
- Cu — содержание меди в руде; R — извлечение; p — оплачиваемая доля; P — цена меди; TC — доля TC/RC и логистики;
- k — коэффициент переноса «лаборатория → промышленность».

| Величина | Формула |
|---|---|
| NSR на 1 т руды | Cu × R × p × P × (1 − TC) |
| Маржа на дополнительную тонну, m | NSR − переменные затраты на добычу и переработку дополнительной тонны |
| Прирост производительности, если мельница — узкое место | δQ = δQ(лаб) × k |
| Экономия энергии, если мельница не узкое место | δE = δE(лаб) × k |
| Выгода от производительности | Q₀·H · δQ · m |
| Выгода от энергии | Q₀·H · E_уд · δE · цена эл. энергии |
| Выгода от извлечения | Q₀·H·(1 + δQ) · Cu · δR(лаб)·k · p · P · (1 − TC) |
| Стоимость реагента на 1 т руды, c | доза(актив) / доля актива / 1000 × цена продукта |
| Затраты на реагент и флокулянт | Q₀·H·(1 + δQ) · (c + Δфлокулянт) |
| Безубыточный прирост производительности | δQ_бу = c / (m − c) |
| Безубыточный прирост извлечения | δR_бу = c / (Cu · p · P · (1 − TC)) |

Коэффициент переноса k = 0,5 — консервативное допущение. Лабораторный эффект на фабрике обычно не воспроизводится полностью: другая гидродинамика, влияние МСИ и гидроциклонов. Уточняется по промышленным испытаниям.

### 11.2. Пример расчёта
Все исходные числа — **иллюстративные допущения**, их нужно заменить данными фабрики, котировками и результатами опытов:
- 1000 т/ч, 8000 ч/год;
- 0,50 % Cu, извлечение 88 %, оплачиваемая доля 96,5 %;
- Cu 9 500 $/т, TC/RC 15 %;
- переменные затраты на дополнительную тонну 12 $/т;
- доза 50 г/т по активу, продукт 38 % актива по 2,5 $/кг;
- δQ(лаб) = 6 %, δR(лаб) = 0,2 % абс., k = 0,5.

| Показатель | Значение |
|---|---|
| NSR на 1 т руды | 34,3 $/т |
| Маржа на дополнительную тонну | 22,3 $/т |
| Расход товарного продукта | 132 г/т, ≈ 1 080 т/год |
| Стоимость реагента | 0,33 $/т руды |
| Выгода от производительности (+3 %) | 5,35 млн $/год |
| Выгода от извлечения (+0,1 % абс.) | 0,32 млн $/год |
| Затраты на реагент | −2,71 млн $/год |
| **Чистый эффект** | **≈ 2,96 млн $/год** |
| Отдача на 1 $ реагента | 2,1 |
| Окупаемость узла дозирования (150 тыс. $) | меньше 1 мес. |
| **Безубыточный прирост производительности** | **1,5 %** |
| Безубыточный прирост извлечения (без роста производительности) | 0,84 % абс. |
| Безубыточная экономия энергии (без роста производительности) | 39 % — недостижимо |
| Максимальная цена продукта при нулевом эффекте | ≈ 5,2 $/кг |

### 11.3. Выводы для принятия решения
1. **Реагент окупается прежде всего через производительность**, и только если мельница — узкое место фабрики, а руда для дополнительной переработки есть.
   - Экономия электроэнергии при той же производительности окупает реагент только при снижении удельной энергии примерно на 40 %. Это нереально.
   - **Если мельница не лимитирует, внедрять реагент ради энергии нецелесообразно.**
2. **Порог прохода по экономике:**
   - прирост производительности на фабрике ≥ 1,5 % (в лаборатории ≥ 3 % при k = 0,5);
   - либо прирост извлечения ≥ 0,85 % абс., что лабораторией достоверно не измерить.
   - Критерий этапа 2 (δQ(лаб) ≥ 4 %) задан с запасом к этому порогу.
3. **Главные факторы чувствительности** (лист «Чувствительность»): δQ, затем цена меди, затем цена реагента. При δQ = 1 % эффект отрицателен при любой цене реагента ≥ 2 $/кг. При δQ ≥ 3 % эффект положителен во всём диапазоне цен 1,5–4 $/кг.
4. **Эффекты извлечения в экономике учитываются только статистически значимые.** Незначимую лабораторную разницу вносить как 0.

## 13. Отчёт и решение о промышленных испытаниях

**Содержание отчёта:**
1. Характеристика пробы, воды и мелющих тел.
2. Результаты каждого этапа: таблицы и графики τy(Cw), P80(t), кривые флотации, «доза флокулянта – скорость осаждения».
3. Статистика и контрольные карты холостого опыта.
4. Итоговая матрица составов.
5. Выбранные D_опт и D_max.
6. Экономика: калькулятор с фактическими данными.

**Решение «идём в промышленные испытания»** принимается, если одновременно:
1. все барьеры пройдены при D_опт и при 3·D_опт (или выбрана D_max / 3);
2. δQ(лаб) ≥ 4 %;
3. расчётный чистый эффект при k = 0,5 положителен при пессимистичной цене меди (−20 %) и цене реагента (+30 %);
4. замкнутый цикл не показал накопления.

Промышленные испытания — по схеме «без реагента → с реагентом → без реагента» из основного отчёта (раздел 7). Их результаты уточняют коэффициент переноса k.
